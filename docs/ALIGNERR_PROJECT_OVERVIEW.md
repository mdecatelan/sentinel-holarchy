## 🎯 Executive Summary for Alignerr Evaluators

### 1. What problem does this project solve?
The project replaces centralized, capital-intensive, petrochemical plastics and chemical fertilizers with a **decentralized, low-CapEx (< 300 €) network of micro-biorefineries**. 

Operating in an urban workshop in **Clamart (France)**, the system converts raw household biowaste (kitchen scraps, starch, eggshells) into:
1. **Grade A**: High-purity Polyhydroxyalkanoate (PHA) bioplastic (100% ocean-biodegradable and marine-assimilable).
2. **Grade B**: Organic-certified (Ecocert / UAB) liquid biostimulant.
3. **Grade C**: Calcium-buffered humic soil amendment.

## 🏗️ Architecture & Engineering Depth

The codebase is built on **Holarchy Theory** (Arthur Koestler) and is divided into 6 recursive, autonomous modules:

| Module | Core Technology | Codebase Location |
| :--- | :--- | :--- |
| **Holon 0: Microbial Kinetics** | Differential equations, Monod/Haldane kinetics, Mixed Microbial Cultures (MMC), Feast/Famine PHA accumulation, $CaCO_3$ buffering dynamics | `src/sentinel_holarchy/holon0_microbial/` |
| **Holon 1: Hardware & IoT** | ESP32 C++/Arduino firmware, FreeRTOS tasks, PID thermal loop, optical tachometer, 4-phase relay state machine, analog BNC signal conditioning | `src/sentinel_holarchy/holon1_hardware/` |
| **Holon 2: Workshop & QA** | Automated regulatory compliance engine for EU Regulation 2018/848, 2021/1165 (Ecocert / Clotaire database), heavy metal & pathogen ceilings | `src/sentinel_holarchy/holon2_workshop/` |
| **Holon 3: Distributed AI & Metrology** | 785nm OpenRAMAN spectroscopy signal processing, polynomial baseline removal, $C=O$ ester peak integration (~1732 cm⁻¹), automated cryptographic Certificate of Analysis (CoA), persistent Knowledge Ledger | `src/sentinel_holarchy/holon3_intelligence/` |
| **Holon 4: Bioregional Logistics** | Mass balance modeling, collection radius optimization, Île-de-France territorial circularity | `src/sentinel_holarchy/holon4_territory/` |
| **Holon 5: Societal Paradigm** | Life Cycle Assessment (LCA), avoided CO2-eq metrics, zero-microplastic impact evaluation | `src/sentinel_holarchy/holon5_paradigm/` |
